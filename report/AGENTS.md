Report sources live only on Samskrift; never create local LaTeX or bibliography sources.
The local report root contains only `AGENTS.md`, `.gitignore`, `scripts/`, and
`generated/`. Track figure-generation scripts under `scripts/`; put generated
figures and non-source intermediate output under ignored `generated/`. Upload
figure assets used in the report to the mapped Samskrift project.

Prefer vector PDF for generated plots, including colored road maps. Embed the
PDF in Samskrift; PNG is a preview or a fallback for genuinely raster content.
